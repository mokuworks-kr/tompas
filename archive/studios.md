# 아카이브 스튜디오 목록

규칙 수치를 잴 작업을 어디서 모을지 정한다. 취향의 출발점이므로 사람이 거른다. 빼거나 더할 곳에 줄을 긋는다.

- 기준: 보고서, 회사소개서, 브랜드북, 책처럼 여러 쪽이 이어지는 인쇄물을 잘하는 곳. 정면 스프레드 이미지나 공개 PDF를 구할 수 있는 곳.
- 규모: 프로젝트 기준 해외 120, 국내 80에서 시작한다(D-21).
- 링크는 2026-10-02에 열리는 것을 확인했다. '미확인'은 주소를 아직 찾지 못한 곳.

### C. 인하우스 디자인이 강한 기업의 공개 보고서 (30)
PDF가 공개돼 있어 가장 정확하게 잴 수 있다. 아모레퍼시픽, 네이버, 카카오, 현대자동차, LG전자, 삼성전자의 지속가능경영보고서와 통합보고서. 현대카드와 토스는 공개 PDF 보고서가 없고, 우아한형제들과 무신사는 보도 자료만 찾았다.

## 진행

1. 목록 승인 · 2026-10-02
2. 프로젝트 208건 수집(해외 120, 국내 88) → `projects.json`
   - 해외 보고서 회사는 사이트에 개별 작업을 거의 올리지 않는다. 그래서 해외는 Red Dot 수상작 크레딧으로 찾고(544건 중 골랐다. 목록 파일은 2026-10-07 지웠다, git 기록에 있다), 측정은 고객사 공개 PDF로 한다.
   - NOSE는 교통 디자인 회사라 맞지 않았다.
3. PDF 74건 내려받음(국내 25, 해외 49) · 2026-10-02. 해외는 Red Dot 설명으로 웹 전용 16건을 인쇄 수상작으로 바꾼 뒤 받았다.
4. 남은 것
   - `pdf_page`만 있는 6건: 사이트가 스크립트를 막아 브라우저로 받아야 한다.
   - `download`에 실패 사유가 적힌 14건: 봇 차단 5건은 디자이너가 직접 받는다. 인증서 만료(Euram)는 보안 검사를 건너뛰지 않았다.
   - 나머지는 공개 PDF가 없어 Red Dot·스튜디오 이미지로만 본다.
